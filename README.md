# CodeAlpha - Sentiment Analysis

## 📌 Project Overview

This project was completed as part of the CodeAlpha Data Analytics Internship.

The objective of this project is to analyze the sentiment of Twitter tweets using Natural Language Processing (NLP). The project performs data cleaning, text preprocessing, sentiment prediction, and visualization to understand public opinions.

---

## 📂 Dataset

Dataset Used:
Twitter Sentiment140 Dataset

Total Records:
1,600,000 Tweets

Columns:

- Sentiment
- ID
- Date
- Query
- User
- Tweet

---

## 🚀 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- NLTK
- TextBlob
- WordCloud
- Jupyter Notebook

---

## 📊 Project Workflow

1. Import Libraries
2. Load Dataset
3. Explore Dataset
4. Data Cleaning
5. Text Preprocessing
6. Sentiment Prediction using TextBlob
7. Data Visualization
8. WordCloud Generation
9. Final Analysis
